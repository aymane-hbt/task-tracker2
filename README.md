✅ Advanced Task Tracker
An advanced, full-featured task management app built with Next.js, TypeScript, and Tailwind CSS — designed to help users organize tasks efficiently with intuitive UI and multiple workflow views.


✨ Key Features
📋 Multiple Views — Switch between List, Kanban, and Calendar modes

⏱ Time Tracking — Built-in timer to track time spent on individual tasks

🔁 Recurring Tasks & Subtasks — Easily manage complex workflows

🧩 Task Templates — Save reusable task structures for faster creation

📊 Dashboard — View completion stats and progress over time

📦 Data Import/Export — Backup or share task data in JSON format

🌙 Responsive & Theme-Aware — Optimized for all screen sizes and dark mode

⚙️ Tech Stack
Next.js + React

TypeScript

Tailwind CSS

shadcn/ui

Local Storage for persistence (no backend)
